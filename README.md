# villupuram-bustrack-map
# 🚌 Villupuram Bus Crowd & ETA Prototype

A **front-end only demo** that shows five moving buses on a live **Villupuram** city map.  
Each bus updates its position and crowd level every few seconds **without any backend or database**.

---

## ✨ Features
- **Real-time simulation**: Bus markers move randomly across a preset Villupuram route.
- **Crowd indicator**: Green = Available, Yellow = Almost Full, Red = Full.
- **ETA (artificial)**: Each marker shows an estimated arrival time to a sample stop.
